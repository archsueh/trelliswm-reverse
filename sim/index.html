规格边界与置信度（随交付一起读）

已实测确定（置信度：高）

树文法来自本机 app 自己的 layout-*.json / departures.json：split.children 可再放 split，任意深度；恒有一个 desktop 叶子承载浮动窗口；panel.views 多项即 tab group；weights 归一化。相机是 framed 节点 id + 一对历史栈，不是连续缩放引擎。命令 / 快捷键 / 权限 / 47 项设置来自公开 guide 与 bundle 内发布配置，逐字可核。

一处歧义（置信度：中）：本机样本里 framed = "desktop" 时 doc.root 恰好也是 desktop 叶子（全浮动状态），因此「缩到最外」与「单独 frame Desktop」在数据上重合、无法区分。本实现按 guide 的 frame-desktop 语义将两者拆开：everything → root.id、frame-desktop → "desktop"；这属于约定，不是观测事实。

推断或未知（置信度：中 / 低 / 未知）

「dock 到边时新建 split 还是并入既有 split」没有成对前后快照，本实现采用可替换策略（同轴插为兄弟、异轴包一层、根叶子建新根）；手势阈值、easing 曲线、窗口指纹哈希与匹配权重、图片缓存淘汰、许可协议均标 UNSPECIFIED，未实现也未伪造等价性。460ms 动画时长取自日志 SETTLED after 461/464 ms，仅用于过渡观感。
